# Disease Info Website

Static website with multiple informational pages (HTML/CSS/JS). The default entry is `homepage.html`.

## Getting Started

Open `homepage.html` directly in your browser, or use the root `index.html` which redirects to it.

## Live Hosting (GitHub Pages)

If you enable GitHub Pages for this repository (Settings → Pages → Branch: `main`), the site will be available at `https://tranvietbach.github.io/HTML/`.
